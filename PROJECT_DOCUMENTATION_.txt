LOST & FOUND MANAGEMENT SYSTEM
PROJECT DOCUMENTATION

PROJECT OVERVIEW
A Django web app for reporting lost/found items, searching records, viewing details,
editing/deleting items, and tracking LOST, FOUND, and RESOLVED status.
Data is stored in CSV/JSON files, with uploaded images stored in media/images/.

DATA STORAGE
CSV fields:										(CSV - contains all our data)
title, status, category, location, date, description, contact, image

JSON is synchronized with the CSV.
Images are saved with UUID filenames to avoid conflicts.

MAIN FUNCTIONS IN views.py
read_items()
  → Reads all items from CSV.

write_items(items)
  → Saves the item list back to CSV.

sync_json(items)
  → Updates the JSON copy.

_save_uploaded_image(f)
  → Saves an uploaded image using a unique UUID filename.

read_json()
  → Reads the JSON file; currently used only for reference.

VIEW FUNCTIONS
home(request)
  → "/" | GET
  → Shows total, lost, found, resolved counts and recent items.

items(request)
  → "/items/" | GET
  → Lists items and supports:
    ?q=laptop              → Search title/location
    ?status=LOST           → Filter by status
    ?q=phone&status=FOUND  → Search + status filter

report(request)
  → "/report/" | GET/POST
  → GET shows the form.
  → POST creates an item, optionally saves an image, updates CSV/JSON,
    then redirects to the items page.

detail(request, item_id)
  → "/items/<id>/" | GET
  → Shows one item. The ID is the item's 0-based position in the CSV list.

edit_item(request, item_id)
  → "/items/<id>/edit/" | GET/POST
  → GET shows the current data in a form.
  → POST updates the item and CSV/JSON, then redirects to its detail page.

delete_item(request, item_id)
  → "/items/<id>/delete/" | POST
  → Removes the item with pop(), updates CSV/JSON, then redirects to the list.

BASIC DATA FLOW
Create:
  /report/ → form → report() → read CSV → add item → save CSV/JSON → /items/

View:
  /items/<id>/ → detail() → read CSV → get item → show details

Search:
  /items/?q=laptop&status=LOST → items() → filter by title/location + status

Edit:
  /items/<id>/edit/ → edit_item() → load item → update → save CSV/JSON

Delete:
  /items/<id>/delete/ → delete_item() → pop(item) → save CSV/JSON

HOW TO RUN
1. Activate the virtual environment:
   cd d:\VS\Project2.0-main
   .\djangoP\Scripts\Activate.ps1

2. Enter the Django project:
   cd lost_and_found

3. Start the server:
   python manage.py runserver

4. Open:
   http://127.0.0.1:8000/

Other useful URLs:
   /items/
   /report/
   /admin/

Stop server with Ctrl+C.
